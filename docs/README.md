# Protocol notes

These device notes come from the upstream BatteryHub project. They document
captured frames, firmware behavior and model-specific limits. References to
the original tray UI or BatteryHub command-line tools describe that project.

This fork's build and widget usage are documented in the root README. Native
source files are under native/src. BatteryProtocols --json returns one device
snapshot; normal use goes through the WidBar widget.
